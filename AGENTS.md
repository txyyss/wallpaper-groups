# Project instructions for Codex

Before editing code, read and follow:

- `docs/AGENTS.md`
- `docs/ROADMAP.md`
- `docs/PROGRESS.md`
- `docs/references/PAPER_GUIDE.md`

Treat `docs/ROADMAP.md` as the normative project plan. The active task is the
first unchecked milestone in `docs/PROGRESS.md`. Work on only one milestone at
a time. Do not commit `sorry`, `admit`, new axioms, or opaque placeholders.
Keep `lake build` passing. Record material design decisions under `docs/`.
Use Conventional Commits for commit messages (for example, `feat:`, `docs:`,
or `chore:`).
